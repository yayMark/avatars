# Avatar Generator

SVG initials-based avatar generator with PNG export.

## CLI

```bash
npm install
node cli.js --initials MH --bg "#C8102E" --circle white --text "#C8102E" --size 200 --output .
```

Args: `initials`, `bg`, `circle`, `text`, `size`, `output`, `name`.

## Web

Open `web/index.html` in browser. Form + live preview + download.

## Output

Generates both SVG and PNG files.
